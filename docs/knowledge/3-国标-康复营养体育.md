## 一、《康复治疗师国家职业技能标准》

**发布部门**: 国家卫生健康委 + 人社部
**标准号**: 国家职业技能标准 2020 版
**职业定义**: 运用物理治疗、作业治疗、言语治疗等技术,评估患者功能障碍,制定并实施康复治疗方案,帮助患者恢复功能、提高生活质量的卫生专业技术人员。

### 等级划分
| 等级 | 名称 | 主要工作 |
|------|------|----------|
| 五级/初级工 | 康复治疗师(初级) | 基础评估、辅助治疗 |
| 四级/中级工 | 康复治疗师(中级) | 独立评估、康复方案实施 |
| 三级/高级工 | 康复治疗师(高级) | 复杂病例、康复团队协调 |
| 二级/技师 | 主管康复治疗师 | 治疗方案设计、质量管理 |
| 一级/高级技师 | 副主任康复治疗师 | 学科建设、科研教学 |

### 核心工作内容
1. **康复评估**: 运动功能、感觉功能、认知功能、言语功能、心肺功能评估
2. **康复治疗**:
   - 物理治疗(PT): 运动疗法、物理因子治疗(电疗/光疗/超声/热疗)
   - 作业治疗(OT): 日常生活活动训练、手功能训练、认知训练
   - 言语治疗(ST): 吞咽训练、构音训练、语言训练
3. **辅助器具适配**: 轮椅、矫形器、辅助具的选用与训练
4. **健康教育**: 康复知识宣教、家属指导
5. **康复记录**: 评估表、治疗单、进展报告书写

### 关联到 RHYTHMIND
- 用户的"康复治疗"标签 → 触发物理治疗课程推荐
- 心肺功能、运动能力数据 → 匹配康复评估指标
- 辅助器具数据 → 个人画像字段

## 二、《公共营养师国家职业技能标准》

**发布部门**: 人力资源和社会保障部
**标准号**: 国家职业技能标准 2023 版
**职业定义**: 从事人群或个人营养状况评估、营养咨询、营养干预、营养教育、营养配餐等工作的专业技术人员。

### 等级划分
| 等级 | 名称 | 主要工作 |
|------|------|----------|
| 四级/中级工 | 公共营养师(初级) | 基础营养咨询、配餐 |
| 三级/高级工 | 公共营养师(中级) | 个体评估、食谱设计 |
| 二级/技师 | 公共营养师(高级) | 群体干预、食疗方案 |
| 一级/高级技师 | 高级公共营养师 | 营养政策研究、培训 |

### 核心工作内容
1. **营养评估**:
   - 人体测量(身高/体重/BMI/腰围/体脂)
   - 生化指标(血糖/血脂/血常规)
   - 膳食调查(24h回顾/食物频率/称重法)
   - 营养风险筛查(NRS-2002/MNA/SGA)
2. **营养咨询**:
   - 个体咨询: 一对一营养评估
   - 团体咨询: 讲座、培训班
3. **营养干预**:
   - 食疗方案设计
   - 营养补充剂建议
   - 肠内肠外营养支持
4. **营养配餐**:
   - 个体食谱设计
   - 团体(学校/养老院/医院)配餐
   - 特殊膳食(糖尿病/肾病/肿瘤)
5. **营养教育**:
   - 中国居民膳食指南
   - 食物成分表应用
   - 营养标签解读

### 关联到 RHYTHMIND
- 用户的"营养"标签 → 触发饮食建议模块
- 体重/BMI/血糖数据 → 营养评估自动评分
- 饮食记录 → 个体化食谱推荐

## 三、《社会体育指导员国家职业技能标准》

**发布部门**: 国家体育总局 + 人社部
**标准号**: 国家职业技能标准 2019 版
**职业定义**: 在群众性体育活动中从事运动技能传授、健身指导、组织管理的人员。

### 等级划分
| 等级 | 名称 | 服务对象 |
|------|------|----------|
| 五级/初级工 | 社会体育指导员(初级) | 社区/初级学员 |
| 四级/中级工 | 社会体育指导员(中级) | 健身俱乐部 |
| 三级/高级工 | 社会体育指导员(高级) | 专业训练 |
| 二级/技师 | 高级社会体育指导员 | 教练员培训 |
| 一级/高级技师 | 国家级社会体育指导员 | 赛事组织 |

### 核心工作内容
1. **运动技能传授**:
   - 基础体能训练(柔韧/力量/耐力/协调)
   - 专项运动技术(跑步/游泳/球类/操课)
2. **健身指导**:
   - 体能评估(心肺/肌力/柔韧/平衡)
   - 运动处方(FITT 原则:频率/强度/时间/类型)
   - 特殊人群指导(慢病/老年/孕产)
3. **组织管理**:
   - 活动策划与执行
   - 赛事组织
   - 安全管理
4. **运动促进**:
   - 全民健身活动
   - 社区体育指导
   - 体质监测

### 关联到 RHYTHMIND
- 用户的"运动"标签 → 触发运动指导
- 跑步数据/心率 → 匹配运动处方建议
- 训练计划 → 按 FITT 原则生成

## 三本标准共同点 (跨域融合)

| 维度 | 康复 | 营养 | 体育 |
|------|------|------|------|
| 评估 | 功能障碍 | 营养状况 | 体能水平 |
| 干预 | 物理/作业/言语治疗 | 食疗/营养教育 | 运动处方 |
| 教育 | 康复指导 | 营养教育 | 健身指导 |
| 工具 | 评估量表、辅助具 | 食物成分表 | 运动处方 |
| 数据点 | 关节活动度、肌力 | 热量、宏量营养素 | VO2max、心率 |

## RHYTHMIND 健康平台整合方向

1. **多维评估引擎**: 一个用户可同时有 3 个维度的标签(康复/营养/运动)
2. **跨域建议生成**: 营养+运动 组合建议(如糖尿病用户的运动+饮食)
3. **合规参考**: 服务推荐时引用国家标准作为背书
4. **教练匹配**: 按用户状态推荐合适等级的专业人员
