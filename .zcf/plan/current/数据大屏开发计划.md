**设计风格**：运动健康（活力橙 #FF6B35 / 健康绿 #4CAF50）
**创建时间**：2026-05-15 12:05:25

## UI/UX 设计指导

### 色彩系统
```
Primary:      #FF6B35 (活力橙 - 强调/CTA)
Secondary:    #4CAF50 (健康绿 - 成功/正向指标)
Accent:       #2196F3 (科技蓝 - 信息/图表)
Warning:      #FF9800
Danger:       #F44336
Background:   #0F0F0F
Surface:      #1A1A1A
Text Primary: #FFFFFF
Text Secondary: #A0A0A0
```

### 字体系统
```
Headline: Inter Bold 32px/48px
Title: Inter Semibold 24px
Subtitle: Inter Medium 18px
Body: Inter Regular 16px
Caption: Inter Regular 14px
```

### 动效原则
```
Micro: 150ms ease-out (按钮/hover)
Transition: 300ms ease-in-out
Entrance: 500ms ease-out
Loading: Skeleton + 脉冲动画
```

## 执行步骤

### 阶段 1：项目初始化
1. 创建 Next.js 16 项目 (npx create-next-app)
2. 安装依赖 (zustand, recharts, leaflet, shadcn)
3. 配置 Tailwind 主题色

### 阶段 2：样式系统
1. 配置 globals.css + 主题变量
2. 设置 CSS 变量

### 阶段 3：状态管理
1. 创建 Zustand stores
2. 创建 API 调用层

### 阶段 4：组件开发
1. KPI 卡片组件
2. 图表组件 (line/bar/pie/gauge)
3. 运动轨迹地图组件
4. Shadcn UI 组件

### 阶段 5：页面开发
1. 数据大屏页面 (bigscreen)
2. 仪表盘页面 (dashboard)
3. AI 报告页面 (report)

### 阶段 6：响应式适配
1. 移动端适配
2. 平板适配
3. 大屏优化

- 首屏加载 < 2s (3G)
- Lighthouse Performance > 90
- 交互响应 < 100ms
- 移动端适配 iPhone 12 / iPad Pro
- 无障碍 WCAG 2.1 AA
