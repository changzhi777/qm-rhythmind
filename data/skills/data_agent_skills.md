# DataAgent 技能库

## report_template_running
**Agent**: data_agent
**触发条件**: sport_type = running
**说明**: 跑步数据解读报告模板

跑步数据重点关注：
1. 心率区间分布（Z2 为有氧基础，Z4/Z5 超过 20% 需警惕过度训练）
2. 配速与心率的关系（有氧跑配速/心率比例是耐力进步的关键指标）
3. HRV 趋势（下降超过 15% 建议增加恢复日）
4. 步频（理想范围 170-180 步/分钟）

## report_template_general
**Agent**: data_agent
**触发条件**: sport_type = general
**说明**: 通用健康数据解读模板

通用数据解读优先级：
1. 睡眠质量（< 6h 影响运动表现和恢复）
2. 静息心率趋势（持续上升可能是疲劳或疾病前兆）
3. 日步数（> 8000 步与健康风险降低相关）
4. HRV（心率变异性，高 HRV 代表恢复状态良好）

## hr_zone_analysis_running
**Agent**: data_agent
**触发条件**: task_type = upload_data, sport_type = running
**说明**: 跑步心率区间分析方法

5 区模型（基于最大心率 %）：
- Z1（< 60%）：恢复跑，增氧暖身
- Z2（60-70%）：基础有氧，脂肪燃烧最高效区间
- Z3（70-80%）：有氧耐力，适合中长跑
- Z4（80-90%）：无氧阈，提升配速上限
- Z5（> 90%）：最大强度，短时间冲刺

80/20 原则：80% Z1-Z2 + 20% Z3-Z5，是大多数业余跑者的理想分配。
